# Krita Keyboard Shortcuts Reference

## 🖱️ Navigation
| Shortcut | Action |
|----------|--------|
| **Middle Click / Space + Drag** | Pan Canvas |
| **Shift + Space + Drag** | Rotate Canvas |
| **Ctrl + Space + Drag** | Zoom In/Out |
| **5** | Reset Zoom to 100% |
| **1** | Reset Rotation |

## 🖌️ Brush & Tools
| Shortcut | Action |
|----------|--------|
| **B** | Brush Tool |
| **E** | Toggle Eraser Mode (Current Brush) |
| **[ / ]** | Decrease / Increase Brush Size |
| **I / O** | Decrease / Increase Opacity |
| **K / L** | Darken / Lighten Current Color |
| **Shift + Click + Drag** | Change Brush Size (on canvas) |

## 🎨 Color & Layers
| Shortcut | Action |
|----------|--------|
| **Ctrl** | Color Picker (While Brush is active) |
| **R** | Select Layer (Pick layer from pixel) |
| **Insert** | New Paint Layer |
| **Ctrl + G** | Group Layers |
| **Ctrl + E** | Merge Down |
| **Alpha Lock (Icon)** | Lock Transparency (Essential for shadows) |

## ⚡ Productivity
| Shortcut | Action |
|----------|--------|
| **Tab** | Canvas-Only Mode (Hide UI) |
| **M** | Mirror Canvas (Check for mistakes!) |
| **Ctrl + Z / Ctrl + Shift + Z** | Undo / Redo |
| **Ctrl + T** | Transform Tool |
| **Q** | Quick Mask Selection |
